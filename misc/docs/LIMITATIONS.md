# Differences from the physical game

Source for the "Differences from the physical game" section of the BGA wiki page Gamehelpfate.
Written for players: no code, card ids or internals.

## Turn flow

Some rules let the players decide together. On BGA this would stop the game to ask everyone, so play is simplified as follows:

- **Monster attack target** - when a monster can attack more than one hero, the game picks the target instead of the players.

## Not implemented yet

- **Hero selection** - heroes are dealt randomly. Only a solo game lets you pick your hero.
- **Share Gold** - giving or receiving gold from an adjacent hero is not available yet.
- **Difficulty options** - the Long time track and the Monster Dice variant are available as table options. Not available yet: starting with no gold, mana or cards in hand, and starting one step up on the upgrade cost track.
